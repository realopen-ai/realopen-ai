# Agent trace schema 1.1

This version retains the execution, request, round, tool, outcome, prompt-reference, and safe-value structures documented in [schema 1.0](v1.0.md), with the inference changes below. See the [changelog](CHANGELOG.md) for a compatibility summary.

## Inference fields

These fields apply to each round's `inference`. Top-level `inference` reflects the first round; an execution ending before its first round may have only initial settings.

| Field | Meaning |
| --- | --- |
| `requested` | Supplied settings, including values forwarded in the actual provider request. Omitted values may remain `null`; provider/native-tool metadata can also be present. |
| `think` | Resolved thinking setting, or an unknown/provider-managed sentinel. |
| `temperature` | Resolved temperature, or `provider_default` when unexposed. |
| `max_output_tokens` | Resolved output limit, or `provider_default` when unexposed. |
| `sources` | Per-setting provenance: `request_payload`, `model_metadata`, `not_exposed`, or `not_forwarded_by_adapter`. |
| `thinking_observed` | Whether reasoning output was emitted during this round. `false` is not evidence that thinking was disabled. |
| `provider`, `native_tools` | Provider and native-tool mode, when available. |

Resolution prefers actual provider payload values, then exposed local model parameters. Explicit `false` and `0` are preserved. Missing defaults are not guessed. `provider_default` has source `not_exposed`; the Groq adapter's unforwarded thinking flag is recorded as `provider_managed` with source `not_forwarded_by_adapter`.

## Model defaults

Each observed round can include `model_defaults`:

| Field | Meaning |
| --- | --- |
| `lookup_status` | Metadata lookup result; inspect this before relying on parameters. |
| `provider` | Provider supplying or withholding defaults. |
| `parameters` | Exposed local model parameters, when lookup succeeds. |
| `model_modified_at` | Model modification timestamp when supplied by the provider. |
| `fetched_at` | Metadata fetch time; cached metadata can predate the execution. |

Metadata lookup is observational and does not modify inference payloads. Lookup failure leaves unknown settings labeled rather than ending the agent execution.

## Illustrative inference fragment

```json
{
  "requested": {
    "think": null,
    "temperature": null,
    "max_output_tokens": null
  },
  "think": "provider_default",
  "temperature": 1,
  "max_output_tokens": "provider_default",
  "sources": {
    "think": "not_exposed",
    "temperature": "model_metadata",
    "max_output_tokens": "not_exposed"
  },
  "thinking_observed": true
}
```

This is a partial example, not a required model configuration. Readers must accept numeric/boolean values and string sentinels. Earlier records are not enriched retroactively; their `null` settings cannot be interpreted as known effective defaults.
