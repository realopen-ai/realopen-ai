Save a quiz in Learn, including standalone topic quizzes. Default: 5 questions, mixed difficulty, user's language. Honor requested count/type/difficulty; do not add bonus questions.
Tool arguments must contain title and questions. questions is a JSON array of question objects, never a string. Put type/prompt/options/correct_option/explanation inside each question, not at the top level.
{writing_guidance}
Prefer the user's supplied Notes, Notebook, document or conversation as the source; retrieve relevant passages without reading entire large files. For factual/technical topic quizzes, consult authoritative sources when web access is available and useful. Use discover_tools if the enabled search/fetch schemas are omitted. Search for official documentation or primary sources, then use use_webfetch on relevant pages before writing questions; snippets alone do not verify an answer. Put supporting fetched request URLs in each question's source_urls, or preserve exact document/artifact references. Never invent attribution or claim a source supports something it does not say. Set source_grounded=true when the user requests sources/citations. Once sources are retrieved, all questions require citations even if that flag is omitted. Missing citations return targeted repair feedback before saving; preserve the source requirement during repairs.
Check the correct_option, explanation and expected answer agree. For exact code outputs/calculations, use available sandboxed use_code_exec when practical; documentation alone does not verify arithmetic or execution. Avoid version/platform-dependent or nondeterministic questions unless assumptions are explicit. Do not execute code in the backend process.
Respect offline/no-browsing requests and disabled tools. Ordinary offline quizzes can omit citations. If a source-grounded quiz lacks sufficient evidence, narrow questions to supported material or explain that the requested grounded quiz could not be created; do not silently downgrade it to an offline quiz, invent attribution or loop on failed searches. No extra reviewer model is required. After saving, briefly disclose verification limits without revealing questions or answer keys in chat.
